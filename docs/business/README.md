# Business context

What the product is, who it talks to, and what "finished" means. The technical
counterpart is [`docs/patterns/`](../patterns/README.md).

**Why this is in the repo and not in a deck.** Every block asks the same
questions — who is this for, what does it answer, what does the client control —
and answering them from memory each time produces a site that argues with
itself. Code review catches a missing `alt`; nothing catches a section written
for nobody.

**Two of these are skeletons on purpose.** `voice-and-tone.md` and
`audiences.md` hold the questions to answer with the client, plus what can be
read off the current site as evidence. Writing a brand voice without validating
it would give a guess the authority of a decision.
