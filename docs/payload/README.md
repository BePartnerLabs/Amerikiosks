# Payload reference

Vendored Payload CMS documentation — how the framework works, not what this
project decided. Moved here from `.cursor/rules/` (nobody uses Cursor, so the
folder name was lying) after deleting the root `AGENTS.md`, which inlined 69% of
these files verbatim and then spent 99 lines indexing them.

**This is reference, not rules.** For what *this* project learned the hard way,
see [`docs/patterns/`](../patterns/README.md). The distinction matters: mixing
"how Payload hooks work" with "the hook that deleted 20 brands" buries the
second one.

**The five patterns that are actually enforced here** are digested in the root
`CLAUDE.md` — start there, and come to these files when you need the depth.
